Verify a download

Compare the checksum, then check the build attestation. This site is served over HTTP, so a checksum fetched from it only detects a damaged download. The attestation is signed and can be verified independently.

Files: SHA256SUMS, ZFS attestation bundle, UFS attestation bundle.

Verify the checksum

Put SHA256SUMS in the same directory as the images and run this on Linux:

sha256sum -c --ignore-missing SHA256SUMS

On FreeBSD, compare the output of this command with the matching line in SHA256SUMS:

sha256 freebsd-zfs.tar.gz
Verify the build attestation

Put the image and its attestation bundle in the same directory and run this with the GitHub CLI. Use ufs instead of zfs for the UFS image.

gh attestation verify freebsd-zfs.tar.gz \
    --bundle freebsd-zfs.tar.gz.sigstore.json \
    --repo cdf-eagles/freebsd-cloud-img \
    --signer-workflow cdf-eagles/freebsd-cloud-img/.github/workflows/generate_image.yml
